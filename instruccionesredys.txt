  Instrucciones de Uso

  1. Levantar Redis

  cd trading-data-fetcher
  docker compose up -d

  Verifica que esta corriendo:
  docker compose ps

  2. Instalar dependencias

  pip install -r requirements.txt

  3. Ejecutar el Fetcher (ya publica a Redis)

  python -m src.main --days 1

  El pipeline ahora hace 5 pasos: fetch → enrich → Parquet → SQLite → Redis (velas + tick + pub/sub).

  4. Desde un bot, suscribirse a ticks en tiempo real

  import asyncio
  from src.database import RedisManager
  from src.database.redis_client import subscribe_ticks

  async def on_tick(tick: dict):
      print(f"Precio: {tick['price']} | Spread: {tick.get('spread_bps')} bps")

  # Opcion A: Pub/Sub (streaming, se bloquea escuchando)
  asyncio.run(subscribe_ticks(on_tick))

  # Opcion B: Lectura directa (polling)
  async def poll():
      mgr = RedisManager()
      await mgr.connect()

      tick = await mgr.get_tick()              # ultimo tick
      candles = await mgr.get_candles(limit=50) # ultimas 50 velas
      health = await mgr.health_check()         # status

      await mgr.disconnect()

  5. API disponible para los bots
  ┌─────────────────────────────┬───────────────────────────────────────────┐
  │           Metodo            │                 Que hace                  │
  ├─────────────────────────────┼───────────────────────────────────────────┤
  │ publish_tick(tick)          │ Guarda en Hash + publica Pub/Sub          │
  ├─────────────────────────────┼───────────────────────────────────────────┤
  │ get_tick()                  │ Lee snapshot del Hash                     │
  ├─────────────────────────────┼───────────────────────────────────────────┤
  │ store_candles(candles)      │ Guarda en ZSET (max 100)                  │
  ├─────────────────────────────┼───────────────────────────────────────────┤
  │ get_candles(limit=100)      │ Lee ultimas N velas                       │
  ├─────────────────────────────┼───────────────────────────────────────────┤
  │ get_candles_since(since_ms) │ Velas desde timestamp X                   │
  ├─────────────────────────────┼───────────────────────────────────────────┤
  │ health_check()              │ Estado de conexion y contadores           │
  ├─────────────────────────────┼───────────────────────────────────────────┤
  │ subscribe_ticks(callback)   │ Loop infinito Pub/Sub con auto-reconexion │
  └─────────────────────────────┴───────────────────────────────────────────┘
  Patrones implementados

  - Singleton: RedisManager() siempre devuelve la misma instancia — una sola pool de conexiones por proceso
  - Resiliencia: Cada comando Redis pasa por _execute() con reintentos exponenciales y reconexion automatica
  - Atomicidad: Las escrituras usan pipeline(transaction=True) — Hash + Pub/Sub se ejecutan juntos o no se ejecutan
  - TTL de seguridad: El Hash expira en 60s (dato stale guard), el ZSET en 1h
